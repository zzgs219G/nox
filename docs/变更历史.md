## 2026-11-13 段架构重定：两套 VMP 各占三段 + 字节码不再加密

**背景**：原方案（11-12）把 VMP 的字节码和 descriptor 表抽进 `.ncr`/`.nct`，
结果锁箱锁了一堆 wrapper 壳，真逻辑（解释器 + 字节码）全在箱外。
而且两套 VMP 共用段名，链接后互相覆盖（见 K-06）。

**改动**：

1. **段名按套分开**（`amice v0.1.6-nox15/nox16`）
   - 第一套：`.ncr` 解释器 / `.ncq` 字节码 / `.ncs` 表
   - 第二套：`.nct` 解释器 / `.ncv` 字节码 / `.ncw` 表
   - 由 `AMICE_VM_INSN_SECTION` / `AMICE_VM_DATA_SECTION` 环境变量控制
2. **`.nct`/`.ncv` 不加密**（体积优先）
   - 实测：加密后 APK 压后 `.ncv` 37KB→128KB（+91KB）、`.nct` 45KB→104KB（+59KB）
   - 加密段熵 8.0，zlib 压不动，代价是硬开销
   - 强度增益接近零：解释器是通用 VM 规则（Amice 开源可抄）、必须能执行所以运行期必然内存明文、所有段共用同一 master
3. **加第四把钥匙 `k_bc2`**（label `nc-dex-v1`）给 `.ncv` 用，不复用 `k_nct`
   （RC4 流密码共用 keystream = two-time-pad）

**验证**：真机跑通；产物 9 段全部符合预期；`readelf` 权限列与加密状态一致。

**关联**：K-06（段名相同导致混淆）、K-07（段名重复导致双重加密）

## 2026-11-13 自检报告（`nc_guard_report.c`）

**背景**：排障时"不知道锁没锁上、位置对不对、VMP 有没有生效、几套"，
每轮都要重构建 + 反汇编 + 手工比对，且多次因此推错方向。

**改动**：解锁后自动打一份体检报告到
`/storage/emulated/0/Android/data/<包名>/files/ncguard_log.txt`，
开关是哨兵文件 `/storage/emulated/0/xixin_debug`（与 sigcheck 共用）。

内容：段名/大小/权限/熵/用途/判定、VMP 套数、解释器可执行性、体积。

**三个关键设计决定**（都踩过坑，见 K-10）：
- 缓冲放**栈上**（全局数组会撑大 `.bss` → 改页面归属 → SIGILL）
- 熵从**内存**读（读文件会把已解密的段报成密文，比没报告更糟）
- 小样本（<512B）不下结论（196 字节算出的熵不可靠）

**验证**：V12（6 项断言，含"判定列必须对齐"的反向验证）。

## 2026-11-13 VMP 寄存器限制的评估结论（未改代码）

**问题**：dex2c 产物的函数寄存器需求 27 个值 > VM 可用寄存器，
Amice 报 `register pressure ... values=27 vregs=32 free=0` 并跳过。

**评估结果**（读 Amice 源码）：

| 方案 | 可行性 |
|---|---|
| 启用 `q.lowering`（用 SIMD 寄存器 v0~v31） | ❌ `WideRegisterPolicy` 枚举只有 `Disabled`，**源码里没有启用路径** |
| 改进 spill 的 liveness 分析 | ⚠️ 可行。`materialize_value` 的 reload 机制已现成、`DominatorTree` 也有现成实现，但 `last_uses` 的槽位回收也受 `pinned` 约束，两处要一起改。估 **300~600 行 / 2~4 周 / 风险中高** |
| 拆函数 | ✅ 项目已用过（`ncguard_stub_recover` 拆四次），但 dex2c 产物是引擎生成的一整个方法，无法手工拆 |

**当前结论**：不改。dex2c 产物的寄存器压力是结构性的
（Dalvik 局部变量天然跨 block），不值得为它改 VMP 内核。
`.ncx` 的段加密就是为这些函数付的代价。

## 2026-11-13 攻防成本模型的修正

**原判断**（错的）：假设攻击者会直奔最贵的路（逆 VM），所以
"`.nct`/`.ncv` 明文 = 防线被跳过"。

**修正**：合格逆向者按性价比排序。

```
① strings / objdump 扫明文         秒级
② 破锁箱解 .ncx                    分钟~小时
③ frida hook 解释器看执行流        分钟（不需要懂 VM）
④ 逆向 VM 语义                     天~周
```

所以 `.ncx` 加密的价值是**把攻击者从 ① 逼到 ③ 或 ④**。
而 `.nct`/`.ncv` 明文只是让最贵的 ④ 少一个前置开销 —— **不等于门开着**。
